# Student-Enrollment-System
This app lets you view and add student, course, and enrollment records.

To run it:
1. Make sure Python 3's installed.
2. Open a terminal in the project folder.
3. Install Flask:
   python -m pip install flask
4. Start the app:
   python app.py
5. Open the address shown in the terminal.

Keep app.py, work.db, and the templates in the folder together.
